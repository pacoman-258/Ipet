Achieved Effect

  • Brain 可通过 google_aistudio provider 调用 Gemini generateContent，并支持把 https://generativelanguage.googleapis.com 这类只填 host 的地址自动规范化成 /v1beta API 基址。
  • /api/brain/models 对 Google AI Studio 不再要求用户填写端点，并会复用保存的 API key；若用户显式提供 host-only endpoint，也会自动补齐正确的 /v1beta/models 路径。
  • Google AI Studio 模型列表现在会按 pageSize=1000 拉取并跟进 nextPageToken 自动翻页，避免只拿到第一页。
  • 定位到真实根因：这台机器访问 Google 依赖本地代理，但原实现对 Google provider 固定 trust_env=False，导致直连超时；同时环境里有 ALL_PROXY=socks5://...，直接信任全部代理环境又会因缺少 socksio 依赖而报 ImportError。
  • Google provider 现改为显式优先使用 HTTPS_PROXY/HTTP_PROXY 这类 http 代理，不再误吃 ALL_PROXY 的 socks 代理，也不再把超时洗成 unknown provider error。
  • Google AI Studio 拉取模型失败时，后端现在会返回真实的 502 错误，而不是伪装成 fallback 成功，便于直接定位真实问题。
  • Human Ops observe 独立模型可用 Google AI Studio 多模态接口读取截图，发送 inline image data。
  • 设置页对 Brain 和 observe 都提供 Google AI Studio 选项，选中后端点输入会禁用并提示只需 API Key。
  • 桌面主进程保存配置时保留 Brain provider/API key 以及 observe provider/API key，避免应用重开后丢失 API 配置。
  • 设置页静态资源现在带 Cache-Control: no-store，并把 settings.js 资源版本升到 v=9，避免 Qt WebEngine 继续复用旧脚本导致用户看到过期的 401 报错。
