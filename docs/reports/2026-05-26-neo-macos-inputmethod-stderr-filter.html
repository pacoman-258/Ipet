macOS 输入法 stderr 噪声过滤报告

本轮处理启动终端出现的 TSMSendMessageToUIServer 和 IMKCFRunLoopWakeUpReliable 输出。它们来自 macOS 输入法/Text Services 底层，不是 Ipet 自身异常。

状态

DONE

启动入口现在会在 macOS 上安装一个窄范围 stderr 过滤器，只过滤已知输入法系统噪声，普通 Python 错误和其他原生 stderr 仍会输出。

已改内容

  • main.py：新增 macOS 原生 stderr 噪声识别函数和启动时过滤器。
  • tests/test_main_runtime_env.py：新增回归测试，确保只匹配这两类已知输入法噪声。

达成效果

  • 过滤 TSMSendMessageToUIServer: CFMessagePortSendRequest FAILED。
  • 过滤 error messaging the mach port for IMKCFRunLoopWakeUpReliable。
  • 不吞掉普通 traceback、后端错误、Qt 其它错误或服务日志。
  • 如需查看原始 native stderr，可用 IPET_DISABLE_NATIVE_STDERR_FILTER=1 禁用过滤。
