Codex 风格可折叠执行过程

目标

在聊天回复中实时展示整理后的执行过程，统一规划、搜索、观察、动作、审批、验证、阻塞与完成状态，并在完成后自动收起过程、突出最终回复。

Worker / subagent split

单 worker 完成；未使用 subagent。Frontend UI 负责渲染和计时，Brain/Body/Human Ops 只补充既有 SSE 的语义字段，QA 由针对性单元测试与源码契约测试覆盖。

Achieved effect

  • 统一为 planning、searching、observing、acting、waiting_approval、verifying、blocked、completed 八类事件。
  • 当前阶段实时显示旋转或等待状态，阶段切换时结算耗时和完成状态。
  • 观察事件可展示 Brain 发给 Observe 的整理后任务，不展示原始思维链。
  • 完成时自动折叠执行细节，阻塞时保持展开，最终回复保持在面板外并提高视觉权重。
