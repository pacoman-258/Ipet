macOS Unicode 文本输入修复

日期：2026-07-13

Goal

修复 Human Ops 批准输入 URL 后，https:// 被当前键盘布局或输入法错误输入成 httpsa// 的问题。

Worker / subagent split

主 agent 单独完成；未使用 subagent。

Files changed

human_ops/desktop_actions.py、桌面动作与入口回归测试，以及本报告。

Achieved effect

macOS 文本输入优先使用 CoreGraphics 的 CGEventKeyboardSetUnicodeString，按 UTF-16 原样发送文本，不经过键盘布局，也不修改剪贴板。原生事件不可用时保留 AppleScript keystroke 降级，并在双重失败时同时报告原因。

Verification

URL https://example.com/a:b 的冒号和斜杠按完整原字符串进入原生输入器；桌面动作相关测试 88 项通过，Python 编译与 diff 格式检查通过，全量回归 730 项通过。

Remaining work

未向真实应用输入文本；真实烟雾测试会改变应用焦点和输入内容，需要单独批准。运行中的旧 Ipet 进程需要重启后加载修复。

Recommended next step

重启 Ipet，在浏览器地址栏输入一个包含 https://、路径和查询参数的 URL，批准后确认文本逐字一致，再继续提交或导航。
