Desktop Screen Capture Bridge Split

Date: 2026-07-03

Goal

Move the desktop screen capture Qt bridge and default-provider identity unwrapping out of main.py into app/screen_capture_bridge.py, while preserving every legacy main.py export used by existing tests and callers.

Worker Or Subagent Split

  • desktop-shell: kept main.py as the legacy export surface and converted screen capture functions to thin bridge delegates.
  • body: preserved behavior by delegating to existing body.screen_capture implementations.
  • qa-reports: added focused regression coverage and this HTML report.
  • Subagents: none used in this round.

Files Changed

  • app/screen_capture_bridge.py: new Qt-free injected bridge for screen capture delegation and provider unwrapping.
  • main.py: retained old function names as wrappers, injected Qt dependencies through the new bridge, and reused bridge unwrapping for active vision providers.
  • tests/test_desktop_screen_capture_bridge.py: new tests for import isolation, default-provider unwrapping, custom-provider passthrough, and main.py wrapper delegation.
  • docs/reports/2026-07-03-desktop-screen-capture-bridge-split.html: this report.

Achieved Effect

  • app.screen_capture_bridge does not import main, Qt bindings, or body.screen_capture at import time.
  • main.capture_qt_screen_frame_payload, main.capture_macos_screencapture_payload, main._encode_pixmap_frame, and main.collect_screen_observations keep legacy names but delegate through the bridge.
  • Default provider identity unwrapping maps legacy main.py wrappers back to body.screen_capture implementations to avoid recursive calls.
  • Custom injected providers remain custom and are not replaced unless they are the exact default wrapper identity.

Remaining Work

No known functional follow-up for this slice. main.py had broad pre-existing local modifications before this round, so future reviews should keep using focused diffs around screen capture bridge lines.

Recommended Next Step

Continue the desktop split by moving the next isolated bridge surface into app/ with the same pattern: dependency injection in app, legacy wrappers in main.py, and identity-provider regression tests.
