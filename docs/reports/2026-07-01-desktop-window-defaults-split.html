Desktop Window Defaults Split

Goal

Move desktop window flags, translucency, and background color defaults out of main.py into a Qt-neutral helper module while preserving the old public helper names.

Worker / Subagent Split

This worker implemented the split directly in the shared worktree. The main window remains responsible for review and acceptance.

Files Changed

  • app/window_defaults.py: new Qt-free policy helpers for window flags and background/translucency defaults.
  • main.py: imports app.window_defaults and keeps compatibility wrappers for the previous helper names.
  • tests/test_desktop_window_defaults.py: new fake-flag tests for the helper module plus AST/source checks for thin wrappers.
  • docs/reports/2026-07-01-desktop-window-defaults-split.html: this report.

Achieved Effect

The platform policy for macOS vs non-macOS flags and transparent vs opaque background is now isolated from Qt imports. main.py still owns Qt binding objects and environment constants, then delegates the pure decision making to app.window_defaults.

Remaining Work

No known follow-up for this split. The repository was already dirty before this worker started, so unrelated files were left untouched.

Recommended Next Step

Have the main window inspect the wrapper boundary and keep future desktop default policy changes in app/window_defaults.py rather than growing main.py.
