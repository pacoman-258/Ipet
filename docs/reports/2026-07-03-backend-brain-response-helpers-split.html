Backend Brain Response Helpers Split

Goal

Move the brain SSE formatting, brain error sanitization, and completion-to-decision helper logic out of backend/app.py into one FastAPI-free helper module while preserving the legacy app wrapper names.

Worker / Subagent Split

Single worker only. No subagents were used. The main window was treated as validation-only and main.py was not edited.

Files Changed

  • backend/brain_response_helpers.py: new standalone helper module.
  • backend/app.py: compatibility wrappers now delegate to the helper module.
  • tests/test_backend_brain_response_helpers.py: new focused helper and wrapper tests.
  • docs/reports/2026-07-03-backend-brain-response-helpers-split.html: this report.

Achieved Effect

The SSE, redaction, and completion fallback behavior is now testable without importing the FastAPI app. backend/app.py still exposes _sse, _sanitize_brain_error, and _decision_from_completion for existing callers.

Remaining Work

No known remaining work for this split. Broader backend route splits remain outside this task.

Recommended Next Step

Keep later brain response behavior changes in backend/brain_response_helpers.py first, then use the app wrappers only as compatibility boundaries.
