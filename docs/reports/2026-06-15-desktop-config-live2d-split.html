Desktop Config and Live2D Split

Date: 2026-06-15

Goal

Continue the second main.py split by moving desktop configuration helpers and Live2D asset helpers into target module homes while preserving the existing main compatibility API.

Worker Split

  • desktop-shell worker: kept main.py wrappers for patched globals such as ROOT_DIR, CONFIG_PATH, and DEFAULT_CONFIG.
  • body worker: moved model path, motion, expression, lipsync, and generated model helpers into body/live2d_assets.py.
  • qa-reports worker: added focused regression tests and this HTML report.

Files Changed

  • app/configuration.py: new configuration merge, shape cleanup, loading, custom HTTP TTS preset, and pet display-name helpers.
  • body/__init__.py: new Body package marker.
  • body/live2d_assets.py: new Live2D path, scan, lipsync, and action-item helper module.
  • main.py: configuration and Live2D functions now delegate to the new modules while keeping old function names.
  • tests/test_desktop_configuration.py: direct tests for configuration helper behavior and injected config loading.
  • tests/test_live2d_assets.py: direct tests for motion inference, generated model scanning, and lipsync metadata.

Achieved Effect

The desktop host keeps its public helper API, but pure configuration logic now lives in app/configuration.py and Live2D asset logic now lives in body/live2d_assets.py. Existing tests that patch main.ROOT_DIR and main.CONFIG_PATH continue to exercise the wrappers.

Verification

Remaining Work

main.py still contains large desktop shell, active vision, Qt bridge, and settings-panel logic. The next split should avoid touching the existing frontend and backend hot files unless its owner explicitly routes that work.

Recommended Next Step
