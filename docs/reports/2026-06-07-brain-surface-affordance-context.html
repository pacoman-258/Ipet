Brain Surface And Affordance Context Report

Date: 2026-06-07

Goal

让 Ipet Brain 更像人类使用电脑：通过观察当前表面和可用入口，组合 observe、click、type_text、key_press enter 等小动作，推进打开微信、定位联系人、读取聊天信息并回复这类复杂任务。

Worker Split

  • brain: 强化 computer-use prompt，要求复杂任务动作携带 continue_after_approval。
  • human-ops: 将 observe 结果派生成结构化 surface 和 affordances，并注入 ReAct follow-up 与批准后续跑提示。
  • qa-reports: 增加回归测试和本 HTML 报告。

  • brain/llm.py

  • tests/test_brain_structured_replies.py
  • tests/test_neo_backend_contract.py
  • docs/WORKFLOW.md

Achieved Effect

  • “打开微信”会被识别为桌面动作和点击型 App 启动请求，默认 observe prompt 会要求 macOS 屏幕坐标。
  • Dock 微信图标观察结果会派生成 desktop_gui / app_icon / click_to_open affordance，并带可点击坐标。
  • 微信场景可识别搜索框、联系人聊天条目、聊天输入框，并能在同一段观察出现多组坐标时就近绑定。
  • 终端提示符会作为 terminal_shell 的 terminal_prompt affordance，支持输入和回车。
  • ReAct follow-up 和 Human Ops 批准后续跑都会收到 Structured computer-use context，降低 Brain 反复 observe 的概率。

Remaining Work

  • 当前 affordance 抽取仍是轻量规则，真实微信界面的联系人搜索、消息阅读和回复草稿质量仍依赖 observe 模型文字质量。
  • 尚未做真实桌面端到端演练；需要在 Ipet 运行态中用 Dock 微信完成一次人工审批链路验证。

Recommended Next Step

在真实 macOS 桌面上运行一次“打开微信并根据某联系人聊天信息回复”的审批链路，记录 observe 文本、结构化 context 和每次 Brain 决策，再针对实际失败点补 affordance 抽取或 prompt 约束。
