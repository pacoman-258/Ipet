Brain Simple Action Guard Report

Date: 2026-06-07

Goal

让 Ipet 坚持使用当前真实可执行的简单人类动作：观察、点击、输入、回车。真实模型如果返回 launch_app、focus_window、hotkey 等捷径，backend 不应把它交给用户审批后再失败。

Worker Split

  • brain: 系统提示明确当前动作范围只包含 click、type_text、key_press enter。
  • human-ops: backend 在生成审批前拦截不可执行动作，并无副作用地要求 Brain 改成简单人类动作。
  • qa-reports: 增加模型返回 launch_app 时自动纠正到 click 的合同测试，并记录本报告。

Achieved Effect

  • Brain prompt now says not to return launch_app, focus_window, hotkey, scroll, drag, or wait.
  • Chat stream correction catches unsupported proposals before approval and asks Brain to use observe, click, type_text, or key_press enter.
  • Post-approval continuation uses the same guard, so a multi-step task cannot leak unsupported actions mid-chain.
