achieved effect

实测当前主屏原始截图为 2940x1912 像素，CoreGraphics 屏幕 bounds 为 1470x956 点；Ipet 实际送给 VLM 的编码图会缩为 1920x1249。因此 VLM 图片像素到 macOS 点坐标的换算约为 x=0.765625、y=0.765412。后端现在把这段换算上下文传给 follow-up Brain，让 Brain 在输出 propose_act 前能把截图/图像像素坐标换成 macOS 屏幕坐标。Qt 红点预览改为 tooltip 级透明窗口并直接绘制圆点，避免被 Dock 盖住。
