Context Summary Script

Goal

Add a small project-specific summary helper so agents can inspect large Ipet areas without reading raw logs, local data, historical reports, or broad repository context first.

Worker Split

Single Codex worker. Tests were written before implementation.

Files Changed

  • scripts/context_summary.py: added repo, reports, data, and logs summary modes.
  • tests/test_context_summary_script.py: added focused tests for repo, reports, and logs behavior.
  • AGENTS.md: documented when agents should run the summary helper.
  • scripts/README.md: documented the helper command.
  • docs/reports/2026-06-09-context-summary-script.html: added this report.

Achieved Effect

Agents now have a reusable command for compact summaries: python scripts/context_summary.py --repo, --reports, --data, and --logs. The data mode reports metadata only and does not read local memory or conversation contents.

Remaining Work

The helper intentionally stays lightweight. It does not parse arbitrary JSON or CSV contents yet; add narrow modes later only when a real task needs them.

Recommended Next Step

Use the helper before future broad repository, report, data, or log exploration. Keep raw file reads limited to slices identified by the summary.
