Playwright 个人资料与窗口复用

日期：2026-07-13

Goal

选择 Playwright 后询问用户使用哪个个人资料；同一资料已有 Ipet Playwright 会话窗口时复用该窗口。

Worker / subagent split

主 agent 单独完成，未使用 subagent。

Files changed

  • human_ops/playwright_actions.py：个人资料校验、稳定会话映射与窗口复用。
  • brain/llm.py、backend/react_prompts.py：个人资料询问和缺失资料纠正合同。
  • human_ops/proposals.py、backend/app_action_adapters.py：审批中展示个人资料与复用影响。
  • docs/WORKFLOW.md、docs/architecture.md 及相关测试。

Achieved effect

Playwright proposal 必须携带用户明确选择的 arguments.profile。同名资料确定性映射到同一命名 CLI session，因此打开中的 Ipet Playwright 窗口会被复用；不同资料相互隔离。会话名只含资料名称的哈希，不暴露原名。

Remaining work

Playwright CLI 不能安全接管未由该命名会话启动的普通 Chrome 窗口；这种需求需要用户改选人类操作。

Recommended next step

分别用“个人”和“工作”资料执行页面打开，再重复选择“个人”，验证第二次沿用同一窗口与登录态。

Verification

针对性回归 45 项、完整回归 742 项全部通过；语法与差异格式检查通过。
