Human Ops Observe + Click

本轮把 Ipet 的第一批人类式操作能力接入 Neo Aspect：observe 可以自由执行，click 必须先给人类 review，并用红点预览点击位置。

日期：2026-05-26 分支：Neo_Aspect 范围：Brain / Human Ops / Body UI / Settings

修改内容

  • 后端 /api/chat/stream 增加 BrainDecision 分流：observe 直接执行屏幕观察，propose_act: click 生成待审批 Human Ops proposal。
  • 新增 /api/human-ops/proposals/{proposal_id}/decision，批准后才执行 click，拒绝则返回可继续对话的结果。
  • 桌面 host 增加 human_ops_click 命令，macOS 下通过 System Events 执行坐标点击。
  • 聊天 UI 增加 红点点击预览，审批按钮改走新的 Human Ops proposal endpoint。
  • 设置页新增独立 observe_model 配置，可为观察任务单独填写 provider、endpoint、模型名、API key，并支持拉取模型列表。

达成效果

  • Ipet 可以根据 Brain 决策先看屏幕，不需要人类审批。
  • Ipet 想点击时不会直接动手，而是在聊天里显示动作卡片和红点位置，等待人类批准。
  • 审批通过后，点击动作经后端写入桌面命令文件，由 Qt host 执行并回传结果。
  • observe 专用模型配置已经进入公开/私有配置契约，密钥只保存不回显。
