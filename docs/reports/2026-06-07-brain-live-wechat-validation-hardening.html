Achieved Effect

  • The final system prompt now explicitly overrides legacy persona text that says not to think about terminal/TUI surfaces.
  • Observation text with negative visibility, such as no Dock or no WeChat icon, no longer creates fake Dock/app-icon affordances.
  • macOS ps fallback now keeps user app bundles such as WeChat after many lower-value system app bundles, so WeChat appears in live target_candidates.
  • Live request #2 confirmed the structured context no longer reported a fake Dock app icon; it reported the current visible surface as a browser page with no click affordance.
