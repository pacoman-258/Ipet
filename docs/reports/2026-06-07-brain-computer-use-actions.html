Brain Computer Use Actions Report

Date: 2026-06-07

Goal

Optimize Brain toward a human-like computer-use model that can advance complex tasks through observe, click, type, and Enter primitives, using Human Ops approval for side-effecting actions.

Worker Split

  • brain lead: computer-use mental model prompt, stage/surface/affordance guidance, action schema.
  • human-ops lead: reviewable type_text and key_press proposals, approval-driven continuation.
  • desktop-shell: macOS text and Enter desktop command execution.
  • qa-reports: regression coverage, workflow update, and this report.

Achieved Effect

  • Brain prompt now teaches a general computer-use mental model based on stage, surface, and affordance, not only GUI click reasoning.
  • propose_act now documents and supports click, type_text, and key_press actions.
  • Human Ops proposals can review text input and Enter key actions without red-dot previews.
  • The backend can execute approved text and Enter actions through the desktop command bridge.
  • The macOS host can type reviewed text through System Events and press Enter/Return via key code 36.
  • Complex proposals can opt into continue_after_approval: after an approved action executes, the backend observes the new surface and asks Brain for the next reviewable step.

Remaining Work

  • Only Enter/Return is implemented for key_press; broader hotkeys remain future work.
  • Continuation is intentionally gated by continue_after_approval to avoid changing ordinary one-shot approvals.
  • WeChat-specific contact search and message-reading quality still depends on observe model output and future affordance extraction improvements.
  • The worktree remains dirty from earlier rounds; this task avoided destructive cleanup.

Recommended Next Step

Add structured surface and affordance extraction to observe results so Brain receives candidate entries like Dock app icons, chat inputs, browser address bars, and terminal prompts as first-class context.
