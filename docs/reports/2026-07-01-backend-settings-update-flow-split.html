Backend Settings Update Flow Split

Goal

把 backend/app.py 中 settings PUT 的配置合并与密钥保留/清理纯逻辑拆入 backend/settings_config.py，让 FastAPI route 只保留 HTTP 校验、保存和响应编排。

Worker / Subagent Split

本轮由后端拆分子窗口 worker 在共享工作区实现；主窗口只做 fresh 验收。未执行 stage、commit、cleanup 或 revert，也未触碰其它子窗口负责的 main.py、frontend/index.js。
