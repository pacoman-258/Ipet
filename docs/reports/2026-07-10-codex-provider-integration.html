Codex 模型提供方接入

日期：2026-07-10

目标

在 Brain 模型提供方中加入 Codex，复用本机 Codex/ChatGPT 登录与账户侧额度，不要求用户把凭据复制到 Ipet。

Worker / Subagent split

本轮由主 agent 单独完成；未启用 subagent。Brain provider、设置页契约、回归测试、工作流文档与报告由同一实现者维护。

Files changed

  • brain/llm.py：Codex CLI provider、登录检测、受限执行与 JSONL 结果解析。
  • backend/brain_models_route.py、backend/chat_stream_flow.py：允许 Codex 无端点运行。
  • settings.html、settings.js、settings_form.js、settings_model_picker.js：新增本机 Codex 选项及无端点/无 Key 交互。
  • tests/ 中相关 provider、设置页和后端契约测试。
  • docs/architecture.md、docs/WORKFLOW.md：记录安全边界与使用方式。

Achieved effect

设置页选择“Codex（本机账户）”后，可用“拉取模型”检测本机登录，并以 default 使用 Codex 账户默认模型。Brain 调用使用临时、只读、无审批升级的 codex exec 子进程；Ipet 不保存 Codex token。

Verification

Python 编译检查通过；Brain provider、结构化回复、后端契约、设置页与 chat stream 共 134 项定向回归通过。真实账户 smoke test 通过，桥接返回 codex default codex-ok。

Remaining work

当前不把 Codex 用作 Human Ops 的图片观察模型；每次回复会启动一个 CLI 进程，若实际使用中冷启动延迟明显，再评估常驻 app-server。

Recommended next step

在设置页选择 Codex，点击“拉取模型”确认登录，然后用 default 发送正常聊天消息；若冷启动延迟影响体验，再评估常驻 app-server。
