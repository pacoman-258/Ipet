Backend Desktop Command Client Split

Date: 2026-06-28

Status: Complete

Goal

Thin backend/app.py by moving the backend-to-desktop-host command client and Human Ops action bridge into a focused backend module while preserving existing app-level wrapper names and behavior.

Worker Split

Human Ops/backend split worker led the implementation. The app aggregation layer was kept as a compatibility wrapper surface; Body, desktop shell, frontend, and settings files were not edited.

Files Changed

  • backend/app.py: retained _send_desktop_command, _perform_human_ops_click, and _perform_human_ops_action wrappers while delegating implementation to the new module.
  • backend/desktop_command_client.py: added command-file writing, response polling, nonce validation, error handling, and click/type/key Human Ops action helpers.
  • tests/test_backend_desktop_command_client.py: added focused TDD coverage for module independence, command/response behavior, nonce mismatch handling, action payload shape, and source-level app slimming.
  • docs/reports/2026-06-28-backend-desktop-command-client-split.html: this report.

Achieved Effect

  • backend.app no longer contains the desktop response polling body or direct command-file temp replacement.
  • _perform_human_ops_observe remains in backend/app.py and continues to call the app-level _send_desktop_command wrapper.
  • Existing patch points remain compatible: tests can still patch backend_app._send_desktop_command, backend_app._perform_human_ops_click, and backend_app._perform_human_ops_action.
  • Command JSON shape, response path injection, nonce checking, timeout/error semantics, and click/type/key return shapes were preserved.

Remaining Work

No required follow-up for this split. backend/app.py remains a high-conflict aggregation file with unrelated existing modifications from other split work, so future changes should continue to be narrow.

Recommended Next Step

Have the coordinator or QA Reports worker review the focused diff and then continue slimming other Human Ops aggregation seams only with dedicated tests first.
