Desktop Screen Capture Compatibility Exports Split

Goal

Move desktop screen-capture compatibility export creation into app/desktop_screen_capture_wiring.py so main.py only installs the exports, while preserving legacy names, default-provider identities, dynamic patch markers, and __module__ values.

Worker / Subagent Split

Implementation was completed in this subwindow. The main window is responsible for independent review, integration acceptance, and the full regression suite. Concurrent work outside the permitted file areas was left untouched.

Files Changed

  • main.py
  • app/desktop_screen_capture_wiring.py
  • tests/test_desktop_screen_capture_wiring.py
  • docs/reports/2026-07-10-desktop-screen-capture-exports-split.html

Achieved Effect

create_screen_capture_compat_exports now creates and names the complete compatibility surface. The wiring module installs the same generated entries for its own API, and main.py installs a main-owned view with one globals().update(...) call. Runtime lookups preserve bridge patching and the legacy dynamic default_* provider markers for Qt composition, pixmap encoding, macOS capture, Qt capture, and aggregate screen capture.

Remaining Work

No scoped implementation work remains. Full repository regression was intentionally not run because the main-window worker owns it. Existing concurrent worktree changes and the environment's PyQt6/PySide6 duplicate-class warnings were not altered.

Recommended Next Step

Have the main-window worker run the full regression suite and merge this scoped change with the other concurrent desktop wiring work.
