Brain Chat Context Draft Policy Report

Date: 2026-06-07

Goal

让 Brain 在微信回复任务中更高效地使用已经观察到的聊天内容：当 chat_context.recent_messages 已经包含目标联系人的可见消息时，Brain 应基于这些消息起草回复，而不是反复观察同一段聊天记录。

Worker Split

  • brain: 在系统提示中明确 recent_messages 是 read_context 阶段的可用证据。
  • human-ops: 在审批后 continuation prompt 中提醒 Brain 使用已有聊天依据推进下一步。
  • qa-reports: 增加 prompt 契约测试，覆盖模型不应因已有聊天上下文而重复 observe 的规则。

Achieved Effect

  • Brain prompt now names chat_context.recent_messages as sufficient read-context evidence when present.
  • Approval continuation prompts now say to draft or send from available chat context and not repeatedly observe the same messages.
  • The WeChat reply chain can move from read context to focus/type/send with fewer redundant observe turns.
