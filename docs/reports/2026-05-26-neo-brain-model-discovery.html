Neo Brain 模型发现报告

本轮给 Web 设置页增加了“一键拉取模型列表并点击填入”的能力，支持 OpenAI 兼容、Ollama、Anthropic 兼容三种 provider。

状态

DONE

用户可以在设置页填写 provider、endpoint 和 API key，点击拉取模型；返回的模型按钮可直接填入 Brain 模型名称字段。草稿配置不会被保存，密钥不会回显。

达成效果

  • 新增 BrainModel 和 list_provider_models，统一解析 provider 返回的模型列表。
  • 新增 /api/brain/models，使用表单里的 draft provider、endpoint 和 key 拉取模型，但不写入配置文件。
  • API key 输入框为空时，后端只会在 provider 没变的情况下复用已保存密钥。
  • 设置页 Brain 区块新增模型发现 panel，点击模型按钮即可填入 brain-model-name。
  • 错误返回会经过既有 Brain 错误脱敏逻辑，避免把 key 或 endpoint 直接回显。
