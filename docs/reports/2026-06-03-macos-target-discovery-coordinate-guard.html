macOS 目标发现与坐标守门修复

Goal

修复 Ipet 在真实 observe/click 链路中暴露的三个问题：macOS 目标发现因 System Events -10827 和 AppKit 缺失退化失败、observe 返回残缺坐标时继续交给 Brain 猜、Brain follow-up 空返回时丢失观察事实。

Achieved Effect

  • System Events 窗口枚举失败时，active vision 不再只剩无用后台进程或空目标；可通过真实 .app bundle 路径得到 app-level focus 候选。
  • 缺少 AppKit 时，仍可通过 System Events running app 和 /bin/ps -axo comm= 提取 GUI app 候选。
  • observe 返回 x=、只有 x、只有 y、或提到可点击中心但没有完整坐标时，Human Ops 明确标记 observe_coordinate_incomplete。
  • 聊天流在残缺坐标时不生成 Human Ops click proposal，也不把残缺坐标交给 Brain 猜测。
  • Brain follow-up 空文本或 provider empty-text error 时，保留 observe 事实并提示补完整 x/y。
