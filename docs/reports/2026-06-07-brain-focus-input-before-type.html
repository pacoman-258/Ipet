Brain Focus Input Before Type Report

Date: 2026-06-07

Goal

让微信回复链路更像真实人类操作：聊天输入框只是可见时不能直接 type_text，Brain 需要先确认键盘焦点；没有聚焦或光标证据时，应先提出点击输入框的 focus_input 动作。

Worker Split

  • brain: 在系统提示中明确可见输入框和可直接输入的区别。
  • human-ops: 在结构化 chat_context 中区分 input_ready 和 input_focused，并把聊天输入框标为可点击入口。
  • qa-reports: 增加 prompt、affordance、chat context、post-approval observe prompt 的契约测试。

Achieved Effect

  • Brain prompt now says: if the input box is visible but not focused, first click it in focus_input.
  • Structured context now carries input_focused, so Brain can distinguish visible input from current keyboard target.
  • Chat input affordances now include click, matching the human action of focusing the text box before typing.
  • Post-approval observe prompts now ask whether the chat input is focused or has a cursor.
