Brain Default Continue After Approval Report

Date: 2026-06-07

Goal

防止复杂电脑操作在第一步获批执行后断链：当 Brain 漏写 continue_after_approval，但 goal 仍指向非终态阶段时，backend 应为桌面/聊天任务默认继续观察并请求下一步 Brain 决策。

Worker Split

  • brain: 仍通过 goal 表达当前阶段、后续阶段和审批 handoff。
  • human-ops: 在创建 proposal 时根据非终态 goal 自动补齐 continue_after_approval。
  • qa-reports: 增加模型漏字段时仍能继续到下一条审批动作的契约测试，并记录本报告。

Achieved Effect

  • Proposal creation now detects non-terminal desktop/chat operation goals with a remaining stage or next.
  • If Brain did not explicitly set continue_after_approval, backend adds it before storing the pending Human Ops proposal.
  • Approving the first action in a complex WeChat reply goal now still triggers post-action observe and the next reviewable proposal.
