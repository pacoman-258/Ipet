Desktop Click Preview Split

Goal

Move desktop click preview payload normalization and overlay widget logic out of main.py into app/click_preview.py, while preserving the existing DesktopPet.show_click_preview behavior and public compatibility entries.

Worker / Subagent Split

This subwindow worker implemented the split directly in the shared worktree. The main window remains responsible for later review and acceptance.

Files Changed

  • app/click_preview.py: new module for normalization and Qt-injected overlay class creation.
  • main.py: imports the new module, re-exports normalize_click_preview_payload, and builds ClickPreviewOverlay from injected Qt dependencies.
  • tests/test_desktop_click_preview_split.py: new split coverage for module isolation, payload semantics, compatibility entries, and fake-widget overlay behavior.
  • tests/test_main_runtime_env.py: updated the existing click preview overlay test to assert the new module-backed compatibility path.
  • docs/reports/2026-06-30-desktop-click-preview-split.html: this report.

Achieved Effect

Click preview behavior now lives in app.click_preview without importing main.py. Invalid payloads still hide the overlay, valid payloads still show a red dot at the normalized screen coordinate, and labels still populate the tooltip.

Remaining Work

No known functional follow-up for this split. Broader cleanup of unrelated dirty files was intentionally left untouched.
