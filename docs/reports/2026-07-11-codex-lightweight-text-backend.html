Codex 轻量文本后端优化

日期：2026-07-11

Goal

保留本机 Codex 登录与模型通道，但移除 Codex 自带 Agent 能力的固定上下文开销，由 Ipet 自己负责 Agent、工具、审批、观察、记忆与技能。

Worker / subagent split

主 agent 单独完成；未使用 subagent。

Files changed

  • brain/llm.py：流式和非流式统一优先使用轻量 app-server 线程，替换默认 Agent 指令并关闭非必要工具；保留 codex exec 兼容回退。
  • tests/test_brain_llm_providers.py：覆盖轻量线程参数、真实 usage 解析和 CLI 回退。
  • docs/architecture.md、docs/WORKFLOW.md：记录新的责任边界和运行路径。

Achieved effect

相同的“只回复 OK”真实探针，input token 从 14,250 降至 4,570，减少约 67.9%；模型仍正确回复 OK。

Codex 线程不再暴露 shell、多 Agent、apps、plugins、browser、computer-use、image、search、goals、hooks 和 workspace-dependency 工具。

Verification

  • Python 编译检查通过。
  • Brain provider、结构化回复与后端契约定向回归：114 项通过。
  • 真实 Codex 探针：input 4,570、output 25、total 4,595；其中 reasoning output 18。

Remaining work

剩余约 4.5k input token 属于当前 Codex 服务通道仍携带的基础上下文；若必须继续降低，需要改用直接的轻量模型 API，而不是本机 Codex 账户通道。

Recommended next step

在真实 Ipet 普通聊天中观察几轮 usage；随后按任务类型延迟注入 computer-use 合同，可继续降低 Ipet 自己的提示开销。
