Desktop Action Wiring Split Report

Goal

Move the desktop action compatibility entry creation and wiring out of main.py into app/desktop_action_wiring.py, while keeping the old main patch points available.

Worker / Subagent Split

Implementation worker handled the scoped split. The main window remains responsible for acceptance. No unrelated worker changes were reverted, reformatted, staged, committed, or cleaned.

Files Changed

  • main.py: imports app.desktop_action_wiring and installs the legacy desktop action names through wiring-generated exports.

Achieved Effect

main.py no longer owns the desktop action wrapper definitions. The old names still have __module__ == "main", DesktopCommandRouter still receives the main function objects, and omitted click calls dynamically resolve the current main._post_core_graphics_click so tests can patch it.

Remaining Work

No remaining work for this scoped wiring split. The lower-level app/desktop_action_bridge.py and human_ops/desktop_actions.py behavior was intentionally left unchanged.
