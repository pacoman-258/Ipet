Desktop Runtime Split

Date: 2026-06-09

Goal

Extract the first desktop runtime/service utility layer from main.py into app/desktop_runtime.py while preserving the existing main API surface and test patch points.

Worker / Subagent Split

  • Lead: desktop-shell worker for main.py runtime/service utility split.
  • QA role: focused unit tests plus existing tests.test_main_runtime_env compatibility checks.
  • Coordinator constraint: no edits to backend/app.py, index.html, settings.js, active vision blocks, or DesktopPet startup flow.

Files Changed

  • app/desktop_runtime.py - new extracted runtime/service helper module.
  • main.py - retained original helper names as wrappers that pass current globals and patchable helpers into the new module.
  • tests/test_desktop_runtime.py - new focused tests for pure runtime logic.
  • docs/reports/2026-06-09-desktop-runtime-split.html - this report.

Achieved Effect

  • Moved Qt runtime env defaults, platform checks, Python command resolution, service log helpers, service health checks, local URL parsing, port probing, and backend launch URL selection into app/desktop_runtime.py.
  • Kept main.Qt, main.requests, main.subprocess, and the existing helper names available for direct imports and mocks.
  • Preserved compatibility for tests that patch main.ROOT_DIR, main.SERVICE_LOG_DIR, main.Path.home, main._preferred_python_commands, main._python_supports_backend, main._python_command_exists, and main.requests.get.
