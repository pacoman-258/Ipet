Backend Settings Assets Split Report

Date: 2026-07-03

Goal

从 backend/app.py 拆出 settings 静态资源响应和缺失资源 404 处理， 减少路由函数内重复的 exists 检查与 FileResponse no-store header 拼装。

Worker / Subagent Split

  • backend worker: 负责实际代码拆分、局部测试新增、回归验证和本报告。
  • QA/test-alignment worker: 主窗口发现旧 source tests 仍按 backend/app.py 内联资产响应断言后，负责把测试口径同步到新的 backend/settings_assets.py 边界。
  • main window: 按用户安排仅做检查，不参与本轮文件写入。

Files Changed

  • backend/settings_assets.py: 新增 settings 静态资源 spec、no-store header 常量、统一响应 helper 和 404 逻辑。
  • backend/app.py: 保留现有 FastAPI route 函数，将五个 settings 静态资源路由体改为委托新模块。
  • tests/test_backend_settings_assets.py: 新增后端 settings assets 单元测试。
  • tests/test_settings_form_source.py: 将 /settings_form.js source 断言更新为 route 留在 app.py、asset spec 留在 settings_assets.py。
  • tests/test_settings_model_picker_source.py: 将 /settings_model_picker.js source 断言更新为 route 留在 app.py、asset spec 留在 settings_assets.py。
  • docs/reports/2026-07-03-backend-settings-assets-split.html: 新增本轮 HTML 报告。

Achieved Effect

  • settings 静态资源的 no-store cache header 定义集中到 backend/settings_assets.py。
  • settings 静态资源的路径、media type 和原 404 detail 文案集中在 asset spec 中。
  • /settings、/settings.css、/settings.js、/settings_form.js、/settings_model_picker.js 路由路径保持不变。
  • backend/app.py 不再在这些 route body 内重复资源存在性检查和 FileResponse header 拼装。
  • 旧 source tests 已对齐新边界：backend/app.py 验 route 和委托，backend/settings_assets.py 验路径、media type、404 detail 和 NO_STORE_HEADERS。

Remaining Work

无本轮阻塞项。主窗口发现的旧 source tests 已由 QA/test-alignment worker 对齐。 仓库中仍有既有未提交的 backend/app.py 大范围拆分改动， 本轮没有回退、清理或格式化其他 worker 的改动。
