DesktopPet 剩余领域职责归位

Goal

完成并审查 DesktopPet 中三类剩余职责的归位：动作列表与 Web 状态同步交给 BodyBridge，配置文件 mtime 与重载交给 DesktopConfigActions，点击预览生命周期与绘制交给 app.click_preview；同时保留 main.DesktopPet 上的兼容薄方法和既有 patch 契约。

Worker / Subagent Split

实现由两个连续子窗口完成：前一子窗口在共享工作树中完成了生产模块与测试的主体改动后被主窗口中断；本子窗口接管当前工作树，完成逐项行为审查、契约测试补强、定向与相关回归以及本报告。主窗口仍负责独立审查与全量回归，本子窗口按任务要求没有运行全量测试。

Files Changed

  • main.py：保留 Body、配置和点击预览的兼容构造入口与薄委托。
  • app/body_bridge.py：承接动作列表刷新、Web 状态同步及既有 Body payload / Web 调用行为。
  • app/desktop_config_actions.py：承接配置 mtime、磁盘重载、面板应用、保存和默认重置。
  • app/click_preview.py：承接预览 payload 归一化、overlay 生命周期和 Qt 绘制。
  • tests/test_desktop_body_payload_bridge.py：补充 main._build_body_bridge 新依赖注入契约。
  • tests/test_desktop_config_actions_split.py：补充 actions 构造后仍动态解析 patched main.load_config 的契约。
  • tests/test_desktop_click_preview_split.py：覆盖 patched main.ClickPreviewOverlay 与薄委托契约。
  • tests/test_main_runtime_env.py：保留 main 运行时与点击预览兼容入口回归。
  • docs/reports/2026-07-10-desktop-pet-residual-responsibilities-split.html：本轮交接与验证报告。

Achieved Effect

  • DesktopPet.refresh_motion_list 与 on_web_state_changed 只委托 BodyBridge；构造器注入 lipsync 提取、动作项生成和 JSON 解析依赖。
  • DesktopPet._config_mtime_token 与 reload_config_from_disk 只委托 DesktopConfigActions；已验证 actions 构造后 patch main.load_config 仍生效。
  • 配置保存后仍调用 owner 的 _config_mtime_token() 更新 _config_mtime，兼容 fake owner 和既有 patch 点。
  • DesktopPet.show_click_preview 与 hide_click_preview 只负责兼容委托；overlay factory 在调用时解析 patched main.ClickPreviewOverlay。
  • 逐行对照拆分前实现后未发现需要修改的生产逻辑；本子窗口只补了缺失的契约测试与报告。

Remaining Work

本拆分没有已知功能缺口。主窗口需要独立复核共享工作树中的最终 diff，并按协调流程运行全量回归；真实 Qt/WebEngine 桌面烟测不属于本子窗口的定向验证范围。
