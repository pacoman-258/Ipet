Frontend Chat Input State Split

Goal

Move chat input availability decisions out of frontend/index.js into a dedicated browser namespace module while keeping the legacy wrapper names used by ASR, chat panel, app config, and chat submit dependencies.

Worker / Subagent Split

This frontend split worker handled the isolated chat input state extraction. No subagent was used, and the main window remains responsible for final review and acceptance.
