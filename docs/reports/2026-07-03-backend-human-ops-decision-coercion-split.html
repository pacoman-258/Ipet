Backend Human Ops Decision Coercion Split

Date: 2026-07-03

Goal

Move the business rules from backend.app._coerce_decision_for_human_ops into the ReAct prompt helper layer while preserving the app-level wrapper API.

Worker / Subagent Split

Single worker only. No subagents were used. The main worker handled the helper extraction, app wrapper update, regression tests, and verification.

Files Changed

  • backend/react_prompts.py: added _coerce_decision_for_human_ops with injected desktop observe/action detectors.
  • backend/app.py: kept the old wrapper name and delegated to backend.react_prompts.
  • tests/test_backend_react_prompts.py: added behavior coverage and wrapper-thinness coverage.
  • docs/reports/2026-07-03-backend-human-ops-decision-coercion-split.html: added this task report.

Achieved Effect

  • Non-SAY decisions are returned unchanged.
  • SAY decisions with an existing goal are returned unchanged.
  • Desktop observe/action-looking SAY decisions without a goal are coerced to BrainDecision.observe.
  • Plain chat SAY decisions remain unchanged.
  • backend.app now keeps only a thin compatibility wrapper for this helper.

Remaining Work

None for this split. Main-window ownership files were not edited and remain outside this task's write scope.

Recommended Next Step

Continue the backend split pattern by moving only one app helper at a time, keeping app wrappers thin and adding focused helper tests before migration.
