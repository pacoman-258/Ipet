Playwright 真实个人资料修复

日期：2026-07-13

Goal

修复个人资料名称只作为 session 标签、没有真正加载持久浏览器资料的问题，并支持连接已打开的普通 Chrome。

Worker / subagent split

主 agent 单独完成，未使用 subagent。

Files changed

  • human_ops/playwright_actions.py：持久资料目录、attach 操作与 v3 session。
  • brain/llm.py、backend/react_prompts.py：区分 Ipet 持久资料和现有 Chrome attach。
  • backend/app_action_adapters.py：审批中说明资料与 attach 影响。
  • .gitignore、工作流、架构文档和回归测试。

Achieved effect

open 现在实际传入 --profile=<哈希目录>，而非只改 session 名；同名 Ipet 资料可跨重启保留 cookies 和登录状态。用户明确要沿用已打开普通 Chrome 时，可使用固定的 attach --cdp=chrome 路径。

Remaining work

普通 Chrome attach 需要 Chrome 允许远程调试；多个 Chrome 资料同时打开且无法区分时仍需用户澄清。未在本轮自动访问网站或连接用户浏览器。

Recommended next step

先用一个新的 Ipet Playwright 资料打开公开页面并登录，关闭后重新打开验证持久状态；再单独验证已打开 Chrome 的 attach 授权。
