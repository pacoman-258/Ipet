Brain Chat Context Post-Approval Observe Report

Date: 2026-06-07

Goal

让 Ipet 在微信回复类复杂任务中，点击进入联系人或会话后能观察并读取最近聊天内容，而不是只泛泛确认界面变化。这样 Brain 才能根据聊天信息草拟回复，再继续提出输入和回车审批。

Worker Split

  • brain: 保持当前 stage 链路，依赖更具体的 post-approval observation 输入来推进 read_context 和 draft_reply。
  • human-ops: 为审批后观察增加任务感知 prompt，微信回复任务会要求目标联系人、最近聊天内容、聊天输入框和发送入口。
  • qa-reports: 增加回归测试，确保批准点击张三聊天条目后，observe prompt 包含聊天上下文读取要求。

Files Changed

Achieved Effect

  • 新增 _post_approval_observe_prompt，审批后观察会携带原始用户目标和刚才获批动作。
  • 微信聊天回复任务的审批后观察会明确要求读取最近聊天内容、确认目标联系人/会话、聊天输入框和发送入口。
  • 新增回归覆盖“点击张三聊天条目后，observe prompt 必须包含张三、最近聊天内容、聊天输入框、发送入口”。

Remaining Work

  • 真实微信端到端演练仍然是完成目标所需证据：需要验证 observe 模型能稳定读取聊天内容并让 Brain 草拟合适回复。
  • 后续可进一步结构化 recent messages，例如把 observe 文本派生成 chat_context 字段，减少 Brain 从自然语言里抽取对话的负担。

Recommended Next Step
