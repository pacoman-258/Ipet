Frontend Speech Split Report

Date: 2026-06-15

Goal

Move frontend TTS, audio playback, lip sync, and expression helper logic out of frontend/index.js into a focused frontend/speech.js controller while keeping existing chat stream call sites stable.

Worker Split

  • frontend speech/TTS split worker: implemented the speech controller extraction, index wrappers, source tests, and this report.
  • Main window / other workers: preserved existing split work in helpers, ASR, sidebars, CSS, backend, main window, and settings files.

Files Changed

  • frontend/speech.js - new window.IpetSpeech.createSpeechController(deps) module.
  • frontend/index.js - removed speech-owned state and implementation details; kept same-name wrappers delegating to speechController.
  • index.html - loads frontend/speech.js after chat_sidebars.js and before index.js.
  • tests/test_frontend_speech_source.py - focused RED/GREEN source test for module existence, load order, and controller delegation.
  • tests/test_chat_modes_ui.py - includes speech.js in split frontend source aggregation and asset checks.

Achieved Effect

  • TTS queue, active audio, audio context, analyser, media source, lip sync RAF, pending speech buffer, expression resolution, browser fallback speech, and TTS playback now live in frontend/speech.js.
  • frontend/index.js still exposes stopSpeaking, setMouthOpen, resolveExpressionName, triggerExpressionSafe, stopLipSyncLoop, startLipSync, fallbackSpeakByBrowser, enqueueTTSChunk, feedSpeakBuffer, and playNextTTSChunk as wrappers.
  • The existing /api/tts request body, audio URL fetch behavior, expression fallback, lip sync gain, and final stream flush behavior were preserved.

Remaining Work

No known follow-up is required for this split. Runtime browser playback remains covered by existing manual app smoke paths rather than a browser automation test in this round.

Recommended Next Step

When the parallel frontend splits settle, run an integrated desktop smoke check that streams one chat response, plays TTS, and confirms mouth movement on the loaded Live2D model.
