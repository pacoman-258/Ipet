Desktop Config Actions Split

Goal

Move the body of DesktopPet.apply_from_panel, save_config, and reset_to_default out of main.py while preserving the old method names as compatibility wrappers.

Worker / Subagent Split

This worker implemented the split directly in the shared worktree. The main window remains responsible for review and acceptance.

Files Changed

  • main.py: imports and builds DesktopConfigActions; keeps the three legacy methods as thin delegates.
  • app/desktop_config_actions.py: new injected action service for panel apply, config save, and default reset behavior.
  • tests/test_desktop_config_actions_split.py: new split tests using fake owner and panel objects, without starting real Qt.
  • docs/reports/2026-06-30-desktop-config-actions-split.html: this report.

Achieved Effect

The configuration action logic now lives outside main.py and does not import main. The new module receives JSON handling, config path, defaults, normalizers, screen provider, and geometry/application hooks through dependency injection. Existing DesktopPet entry points continue to exist and delegate to the extracted service.

Remaining Work

No known functional follow-up for this split. The repository was already dirty before this worker started, so unrelated modified and untracked files were left untouched.

Recommended Next Step

Have the main window inspect the diff for the new injected service boundary and decide whether subsequent DesktopPet actions should be split with the same pattern.
