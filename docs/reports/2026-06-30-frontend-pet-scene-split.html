Frontend Pet Scene Split

Goal

Continue slimming frontend/index.js by moving Live2D/PIXI scene and model control into a dedicated frontend controller while preserving old entrypoint functions as thin delegation wrappers.

Worker / Subagent Split

Single implementation subwindow. Frontend/body presentation ownership handled the scene split; QA report duties were handled in the same worker with focused source tests and command verification.

Files Changed

  • frontend/pet_scene.js: new window.IpetPetScene.createPetSceneController(deps) module.
  • frontend/index.js: delegates model transform, interaction binding, stage interaction, renderer readiness, motion playback, and model loading to the controller.
  • index.html: loads frontend/pet_scene.js after helper/chat modules and before frontend/index.js.
  • tests/test_frontend_pet_scene_source.py: new focused source tests for namespace, load order, wrapper delegation, and scene ownership.
  • tests/test_chat_modes_ui.py: updates split asset order/source aggregation to include the new pet scene module.
  • docs/reports/2026-06-30-frontend-pet-scene-split.html: this report.

Achieved Effect

  • Live2D model state, pending model URL, model cleanup, scale/opacity/rotation clamp, bottom-center placement, edit-mode drag, wheel zoom, hit/tap motion routing, and motion-manager fallback now live in frontend/pet_scene.js.
  • frontend/index.js keeps compatibility wrappers for applyModelTransform, bindModelInteraction, setupStageInteraction, isRendererReady, playMotionCompat, and loadModel.
  • applyConfig remains the coordinator for chat, ASR, sidebar, background, and model config, but model load/transform decisions call through the pet scene controller.

Remaining Work

  • PIXI application construction and follow-mouse ticker setup still remain in frontend/index.js; they can be moved later if the next frontend split wants the scene controller to own app creation fully.
  • No browser/runtime Live2D smoke test was run in this round; validation is source-level plus JavaScript syntax checks.

Recommended Next Step

For the next small frontend split, either move PIXI app creation/follow-mouse focus into the pet scene controller or add a lightweight browser smoke test around model load and edit-mode interaction.
