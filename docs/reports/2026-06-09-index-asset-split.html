Index Asset Split

Goal

拆分 root index.html 的内联 CSS 和主内联 JavaScript 到 frontend/，保持 root 入口和运行时加载顺序不变。

Worker Or Subagent Split

前端拆分 worker 执行第一刀；主窗口职责为检查边界和验证结果。未修改 backend/app.py、main.py、settings.js。

Files Changed

  • index.html: 用 ./frontend/index.css 和 ./frontend/index.js 替换原内联资产块。
  • frontend/index.css: 承接原 <style> 内容。
  • frontend/index.js: 承接原主 IIFE <script> 内容。
  • tests/test_chat_modes_ui.py: 增加合并源 helper，并让 JS/CSS 字符串断言读取拆分后的资产。
  • docs/reports/2026-06-09-index-asset-split.html: 记录本轮拆分。

Achieved Effect

index.html 保留 Qt、Live2D、PIXI、index.min.js 外部依赖顺序和 macOS 平台探测内联脚本；主 app 脚本仍在 body 末尾加载。测试覆盖新增资产引用和文件存在性。

Remaining Work

尚未做 ASR、topics、TTS、Human Ops preview 等内部模块拆分；本轮仅做资产分离。

Recommended Next Step
