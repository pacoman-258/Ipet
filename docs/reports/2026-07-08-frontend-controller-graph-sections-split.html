Achieved Effect

The new controller_graph_sections.js owns grouped wiring for chat input, shell, pet, chat, speech/stream, and bootstrap controllers, mutating the same shared controller registry object. Adjacent tests now assert concrete controller factories, registry writes, and facade wiring parameters against controller_graph_sections.js while leaving controller_graph.js assertions focused on orchestration/delegation.
