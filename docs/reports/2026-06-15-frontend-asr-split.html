Frontend Body ASR Split

Date: 2026-06-15

Goal

Move the root pet UI ASR and push-to-talk subsystem out of frontend/index.js into frontend/asr.js while preserving the existing UI behavior, function names, and ASR backend contracts.

Worker Split

This round was handled by the frontend Body ASR split worker. The main window remained a review/checking owner; this worker only touched the assigned frontend ASR, focused tests, script loading, and report files.

Files Changed

  • frontend/asr.js: new ASR controller module owning ASR state, status text, URL construction, warmup/probe, draft rendering, WebSocket handling, capture pipeline, downsampling wrapper use, and push-to-talk start/stop.
  • frontend/index.js: replaced ASR internals with thin wrappers that delegate to asrController; kept existing function names for event bindings and source tests.

Achieved Effect

frontend/index.js no longer owns ASR capture/socket/session state. The ASR controller uses the existing window.IpetIndexHelpers helpers for config normalization and audio downsampling, and receives chat state, DOM refs, bridge warmup, and input availability sync through dependencies.
