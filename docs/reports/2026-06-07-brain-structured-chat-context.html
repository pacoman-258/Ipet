Brain Structured Chat Context Report

Date: 2026-06-07

Goal

让 Ipet 在微信回复类复杂任务里，不只知道当前 surface 和可操作入口，还能把 observe 看到的联系人和最近聊天内容整理成结构化上下文，帮助 Brain 稳定进入草拟、输入和发送阶段。

Worker Split

  • brain: 接收更稳定的 Structured computer-use context，其中包含 chat_context。
  • human-ops: 从 observe 文本派生联系人、最近消息、输入就绪、发送就绪等聊天上下文字段。
  • qa-reports: 增加 chat context 抽取和 follow-up 文本包含性的回归测试。

Files Changed

  • backend/app.py
  • tests/test_neo_backend_contract.py
  • docs/WORKFLOW.md
  • docs/reports/2026-06-07-brain-structured-chat-context.html

Achieved Effect

  • 新增 chat_context 派生，当前支持从“最近聊天内容：张三：...；我：...”这类 observe 文本中提取最近消息。
  • chat_context 可包含联系人、最近消息、输入框是否可用、发送或回车发送是否可用。
  • _computer_use_context_text 会把 chat_context 一起注入 Brain follow-up，减少 Brain 重新解析自然语言观察的负担。

Remaining Work

  • 当前消息抽取是轻量规则，不覆盖所有微信可见文本格式；真实端到端演练后应按 observe 模型实际输出补格式。
  • 下一步仍需要验证输入后继续观察并提出 Enter 发送审批的真实链路。

Recommended Next Step
