本轮把 Brain 从本地占位回复推进到可配置的大模型 API：支持 OpenAI 兼容、Ollama、Anthropic 兼容三种格式，并在 Web 设置页中由用户选择和填写。

达成效果

  • 新增 brain/llm.py，统一 provider config、消息构造、请求发送、响应解析和错误包装。
  • OpenAI 兼容 provider 使用 /v1/chat/completions，Ollama 使用 /api/chat，Anthropic 兼容 provider 使用 /v1/messages，并统一接收输出上限配置。
  • /api/chat/stream 在用户配置 endpoint 后会调用 Brain runner，并在 SSE meta 中回传 provider 和 model。
  • 聊天流会先发出 meta 和 running phase，再等待模型返回；provider 错误进入前端和历史记录前会做密钥与 endpoint 脱敏。
  • Web 设置页新增 Brain provider 下拉选择，保留原有视觉风格，并避免把 LLM endpoint 写入本地 backend_url。
  • /api/settings/config 继续返回脱敏配置，Brain API key 不会出现在前端读取结果里。
  • README 之外的核心架构与工作流文档已同步说明新的 Brain API 边界。
