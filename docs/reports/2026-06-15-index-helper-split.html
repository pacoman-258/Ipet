Index Helper Split

Goal

Continue the second frontend split by moving pure helper logic out of frontend/index.js into a plain browser script at frontend/index_helpers.js.

Worker Split

Frontend helper worker handled implementation and source-level tests. Main-window role remains review and integration only.

Files Changed

  • frontend/index_helpers.js: new helper namespace window.IpetIndexHelpers.
  • frontend/index.js: kept legacy function wrappers and delegated pure logic to the helper namespace.
  • index.html: loads frontend/index_helpers.js before frontend/index.js.
  • tests/test_chat_modes_ui.py: includes helper source in combined UI source and checks script order.
  • tests/test_index_helpers_source.py: new source sanity tests for exported helpers, wrapper usage, and no DOM/Qt/fetch/navigator dependencies.
  • docs/reports/2026-06-15-index-helper-split.html: this report.

Achieved Effect

Extracted pure helpers including clamp/rate/rounding, chat and memory mode normalization, skill id dedupe, ASR config normalization, audio downsampling, topic and skill record normalization, prompt name parsing, speaker-name formatting, and step metadata formatting. Runtime helpers that depend on state, navigator, ASR base URL selection, DOM, Qt, or fetch stayed in frontend/index.js.

Verification

  • RED: .venv/bin/python -m unittest tests.test_chat_modes_ui tests.test_index_helpers_source -v failed because the helper script and namespace did not exist yet.
  • GREEN: the same helper slice passed after adding the helper bundle and wrappers.
  • Regression and whitespace checks are recorded in the final task handoff.

Remaining Work

frontend/index.js still contains DOM-heavy UI, Qt bridge, ASR URL construction, fetch workflows, and stateful ASR/status helpers. Those should be split in later focused passes.

Recommended Next Step

Next helper pass can target DOM-light state serializers or isolated chat payload builders, while leaving ASR URL construction and Qt bridge behavior in the main frontend script until their boundaries are tested.
