Layered post-action verification

Goal

把动作后验证从“每步截图”改为“动作返回 → 平台原生状态 → 必要时视觉验证”的分层链路。

Worker / subagent split

单 worker 完成；未启用 subagent。

Files changed

human_ops/approval_flow.py、human_ops/approval_prompts.py、架构与工作流文档，以及 Human Ops 回归测试。

Achieved effect

  • 普通打开、点击、输入和按键动作先验证动作标志与原生焦点状态。
  • 结构化验证通过时直接交给 Brain 续推，不截图、不调用视觉模型。
  • 证据缺失或 Brain 明确需要新界面状态时才调用视觉观察。
  • 带 expected_text 的发送 Enter 保留最终视觉验证，避免把按键发出误判为消息已发送。
  • 定向回归 105 项通过；完整回归 729 项全部通过。

Remaining work

本轮未执行真实桌面动作；结构化与视觉降级行为由协议、路由和回归测试验证。

Recommended next step

在用户明确批准后，用“点击输入框 → 输入草稿 → Enter 发送”做真实烟雾测试，确认前两步不截图、发送后只截图一次。
