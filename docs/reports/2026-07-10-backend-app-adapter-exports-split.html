Backend App Adapter Compat Exports Split

Goal

把 backend/app.py 维护的 adapter 兼容符号清单迁移到 backend/app_adapters.py，同时保留旧 patch points、函数身份和路由对 globals() 的动态读取契约。

Worker / Subagent Split

实现由本子窗口完成，包括兼容导出拆分、契约测试、定向回归与本报告；主窗口负责独立审查、集成验收与全量回归。

Files Changed

  • backend/app.py: 用一次 compat installer 调用替代 57 个逐名导入。
  • backend/app_adapters.py: 新增明确的 APP_COMPAT_EXPORTS 和最小 installer。
  • tests/test_backend_app_adapter_exports.py: 新增导出集合、对象身份、installer 边界和动态 patch 契约测试。
  • docs/reports/2026-07-10-backend-app-adapter-exports-split.html: 本轮报告。

Achieved Effect

backend/app.py 不再维护巨大兼容导入块。57 个历史符号由 adapter 模块集中声明并原对象安装，入口上的旧访问路径与 patch 行为保持不变，领域逻辑未改动。

Verification

  • 先新增契约测试；旧结构按预期失败于缺少 export map/installer 和逐名导入仍存在。
  • py_compile: PASS，覆盖两个实现文件和新增测试。
  • 定向 unittest: PASS，138 tests，覆盖 backend route、app adapters、observe 与 Neo backend contract。
  • 未运行全量回归，按任务要求交由主窗口执行。

Remaining Work

本轮范围内无剩余实现项。全量回归和跨工作者集成状态仍需由主窗口确认。

Recommended Next Step

主窗口合并其他并行改动后运行全量 unittest；后续新增 adapter 兼容入口时，只更新集中 export map 和对应契约测试。
