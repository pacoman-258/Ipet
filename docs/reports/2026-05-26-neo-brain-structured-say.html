Neo Brain 结构化 Say 报告

本轮把 Brain 回复从“纯文本”升级为可分类的 BrainDecision：当前只执行 say，同时为 observe、act、remember、learn_skill 和 stop 留出结构化入口。

达成效果

  • Brain prompt 现在要求 provider 返回一个紧凑 JSON 决策，优先形如 {"kind":"say","text":"..."}。
  • 新增 parse_brain_reply，普通文本会自动归类为 say，保证兼容不听 schema 的模型。
  • run_brain_turn 保留 provider 原始文本，同时返回清洗后的用户可见文本和 BrainDecision。
  • 后端 SSE 的 done 事件包含 decision 元数据；token、segment 和 display_segment 只展示 say 文本。
  • observe、act、remember、learn_skill 和 stop 已能被解析或预留，但本轮不执行任何非 say 动作。
