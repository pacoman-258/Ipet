API 代理路径与 Observe 超时优化

Goal

优化 Brain 和 Human Ops observe 的模型 API 网络路径：本地提供方和本地端点直连，远端提供方按可用 HTTP(S) 代理访问；同时放宽 observe 读图模型的超时限制，避免图片识别分析被过早中断。

Achieved Effect

  • Ollama and local OpenAI-compatible endpoints bypass environment proxy settings.
  • Remote OpenAI-compatible, Anthropic-compatible, and Google AI Studio Brain calls can use HTTP(S) proxy environment variables while keeping trust_env disabled.
  • Observe VLM calls keep local_vlm direct, including LAN endpoints, while remote VLM calls can use HTTP(S) proxies.
  • SOCKS-only ALL_PROXY is ignored for these model clients, avoiding failures when SOCKS support is unavailable.
  • Observe model timeout now defaults to 90 seconds and allows custom values up to 300 seconds.
