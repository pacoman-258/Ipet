Brain Type To Enter Continuation Report

Date: 2026-06-07

Goal

推进 Ipet 使用简单人类动作完成微信回复任务的最后阶段：批准输入回复后，Ipet 应观察草稿是否完整进入输入框，并在可发送时提出回车审批。

Worker Split

  • brain: 接收包含 chat_context 和发送就绪信息的 follow-up prompt，再提出 key_press enter。
  • human-ops: 为已批准的 type_text 动作生成草稿感知的 post-approval observe prompt。
  • qa-reports: 增加从输入审批到回车审批的回归测试，并记录本报告。

Files Changed

  • backend/app.py
  • tests/test_neo_backend_contract.py
  • docs/WORKFLOW.md
  • docs/reports/2026-06-07-brain-type-to-enter-continuation.html

Achieved Effect

  • 审批执行 type_text 后，post-approval observe prompt 会包含刚输入的草稿文本。
  • 观察问题会明确要求确认草稿是否完整出现在微信聊天输入框中。
  • 当观察和 Brain 后续决策认为可以发送时，Human Ops 会发出 key_press enter 审批，而不是自动发送。

Remaining Work

  • 仍需真实 macOS + Ipet + 微信端到端演练，验证 observe 模型是否能稳定确认草稿和发送状态。
  • 发送后还应补 verify_result 阶段，观察消息是否真的出现在聊天记录中。

Recommended Next Step

补发送后 verify_result 的回归：批准 Enter 后观察微信聊天记录，确认刚发送的回复可见，然后允许 Brain 用 goal.status=done 结束任务。
