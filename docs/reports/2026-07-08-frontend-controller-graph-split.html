Achieved Effect

frontend/controller_graph.js now owns state/ref/facade/controller registry creation and all controller factory calls. frontend/index.js is reduced to a thin startup entrypoint that creates the graph and calls graph.facade.init(). index.html loads the graph after controller_facade.js and before index.js.

Remaining Work

No known implementation work remains for this split. Broader unrelated working-tree changes existed before this task and were left untouched.
