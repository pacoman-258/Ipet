Ipet Neo Aspect

Ipet Neo Aspect 是本地桌宠产品。新的项目模型只有四个模块：Body、Brain、Human Ops、Memory & Skills。Body 先观察和表达，Brain 每轮只做一步决策，Human Ops 审批风险动作，Memory & Skills 负责长期记忆和技能。

四模块 结构 启动 工作流 测试

四模块模型

Body

桌面宿主、宠物窗口、前端表现、TTS/ASR、本地观察和设备侧执行。

Brain

把当前用户输入、允许的记忆和 Body 观察整理成单步 LLM 决策。

Human Ops

处理审批、拒绝、带约束批准和危险动作的执行安全。

Memory & Skills

保存长期记忆、摘要、偏好、内置技能和学习得到的流程。

目录结构

路径 职责
main.py过渡期桌面宿主入口与 Qt/WebEngine 桥。
backend/过渡期 Python API 表面。
body/目标 Body 模块：宿主、观察、语音、表现和本地动作。
brain/目标 Brain 模块：LLM 单步决策与提示词契约。
human_ops/目标审批、动作复核和执行记录。
memory/、skills/长期记忆、摘要、偏好、技能定义和学到的流程。
app/目标应用组合层。
frontend/根 UI 迁移后的目标前端目录。
index.html、settings.*过渡期仍在根目录加载的桌宠 UI 与设置页。
docs/架构、工作流、所有权和按需报告。

根 UI 文件会保留到桌面宿主和后端加载路径一起迁移为止；不要在迁移前做第二套入口。

本地启动

优先使用项目 .venv 与 Python 3.12。

uv run --no-sync python main.py

本地配置

Copy-Item pet_config.example.json pet_config.json

pet_config.json 只属于本机。不要提交 API Key、本地绝对路径、截图、生成音频或运行状态。

Neo 工作流

启动Body 初始化桌宠、UI、语音和本地观察。
observe/sayBody 收集必要上下文并渲染即时状态。
BrainBrain 只给出一个下一步。
Human Ops危险动作先审批。
execute/observeBody 执行后观察结果。
summary总结终态、证据和剩余未知项。

测试

完整回归命令：

python -m unittest discover -s tests -p "test*.py" -v

编码代理应选择最小相关测试；文档任务通常只需格式检查和针对所改契约的搜索检查。
